# Classic Minesweeper (Web)

A browser-based Minesweeper inspired by the classic Windows version.

## Run locally

Because this is a static app, any basic file server works:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Play online

The easiest way is **GitHub Pages**:

1. Push this folder to a GitHub repository.
2. In repository settings, enable **Pages** from the `main` branch root.
3. Open the generated URL and play.

## Controls

- Left click: reveal a cell
- Right click: place/remove a flag
- Use difficulty selector for easy / medium / hard
